## 🎯 1. แนวคิดหลัก (Core Idea)
เพิ่มฟีเจอร์ **บังคับเปิดหน้าจอค้างไว้ตลอด (Keep Screen Awake / Wake Lock)** ในหน้า **นาฬิกาประจำห้องเรียนเต็มจอ** พร้อมปุ่มกดเปิด–ปิด และขยายการใช้งานไปยังจุดสำคัญของการสอน

---

## ⚙️ 2. สถาปัตยกรรมทางเทคนิค (Dual-Layer Wake Lock)
สร้างโมดูล [`src/utils/wakeLockUtils.js`](file:///w:/Ai/EDcalendar/src/utils/wakeLockUtils.js) ที่ทำงานด้วยระบบ 2 ชั้น:
1. **ชั้นที่ 1 (หลัก) — HTML5 Screen Wake Lock API (`navigator.wakeLock.request('screen')`)**:
   * สั่งล็อกหน้าจอไม่ให้หรี่แสงหรือเข้าโหมดพักเครื่อง (Sleep) โดยตรงผ่านเบราว์เซอร์
   * มีระบบ **Auto-Reacquire** เมื่อสลับหน้าต่างไปเปิดสไลด์สอนแล้วสลับกลับมาที่หน้านาฬิกา (`visibilitychange`)
2. **ชั้นที่ 2 (สำรอง) — Silent 1-FPS Canvas Video Stream Fallback**:
   * กรณีเปิดบนเบราว์เซอร์หรืออุปกรณ์ที่ไม่รองรับ Wake Lock API ระบบจะจำลองสตรีมวิดีโอไร้เสียงขนาด 1x1 พิกเซลในหน่วยความจำเพื่อป้องกันหน้าจอดับ

## 🖥️ 3. จุดที่มีปุ่มใช้งานและฟีเจอร์ต่อยอดที่ติดตั้งแล้ว
1. **ในหน้าต่างนาฬิกาประจำห้องเรียนเต็มจอ ([`LivePeriodTracker.jsx`](file:///w:/Ai/EDcalendar/src/components/Timetable/LivePeriodTracker.jsx))**:
   * ☀️ **ปุ่ม `เปิดจอค้างไว้ (Awake)` / `จอค้าง: ปิด`**: เปิดอัตโนมัติเมื่อเข้านาฬิกาเต็มจอ (จำค่าล่าสุดไว้ใน `localStorage`) และปลดล็อกอัตโนมัติเมื่อกดย่อกลับ (`ESC`)
   * 🔔 **ปุ่ม `กระดิ่งเตือน: เปิด/ปิด`**: สังเคราะห์เสียงกระดิ่งโรงเรียนผ่าน Web Audio API เตือนเมื่อ **เหลือ 5 นาทีสุดท้าย** (สรุปบทเรียน) และเมื่อ **หมดเวลาคาบเรียน**
   * 👁️ **ปุ่ม `ความสว่าง / ถนอมจอ OLED` (100% / 75% / 50% + Pixel Shift)**: ปรับลดความสว่างและขยับตำแหน่งพิกเซลแบบเนียนตาทุก 45 วินาทีเพื่อป้องกันจอเบิร์น
   * 🖥️ **ปุ่ม `ไร้ขอบเต็มจอ (F11)`**: ซ่อนแถบ URL ของเบราว์เซอร์และ Taskbar ด้วย Fullscreen API
   * 🌙 **ระบบตัดโหมดจอค้างอัตโนมัติหลังเลิกเรียน (Auto-Sleep After School)**: หากเปิดทิ้งไว้จนหมดเวลาเรียนประจำวัน (`after_school`) ระบบจะปลดล็อกหน้าจอให้อัตโนมัติ
2. **บนการ์ดนาฬิกาในหน้าตารางสอนหลัก ([`LivePeriodTracker.jsx`](file:///w:/Ai/EDcalendar/src/components/Timetable/LivePeriodTracker.jsx))**:
   * ปุ่ม **`☀️ ล็อกจอค้าง`** สำหรับเปิดจอแท็บเล็ต/โน้ตบุ๊กค้างไว้บนโต๊ะครูขณะดูตารางสอนทั้งสัปดาห์
3. **ในหน้าต่างแผนการสอนและเช็กลิสต์สื่อ ([`SessionDetailModal.jsx`](file:///w:/Ai/EDcalendar/src/components/Calendar/SessionDetailModal.jsx))**:
